## ✨ **Features**

- 🎨 **Dark & Purple UI Theme** — Elegant black background with glowing purple accents.
- ⚙️ **Angular + TypeScript** — Built using the latest Angular 17 features and clean modular structure.
- 🧠 **Interactive Tabs Navigation** — Smooth transitions between sections (Home, About, Experience, Skills, Internship, Contact).
- 💼 **Detailed Experience Section** — Describes professional projects like **UbiCRM**, **HRMS**, and **Recruitment System**.
- 🧾 **Internship Section** — Displays internship certificates and timeline in a card layout.
- 💡 **Skills Section** — Technology badges with hover glow and animations.
- 💬 **Contact Tab** — Unique contact experience with glowing info cards (not just a plain form!).
- 📱 **Responsive Layout** — Optimized for desktop, tablet, and mobile screens.
- ⚡ **Animated Interactions** — Subtle fades, slides, and glow effects using CSS keyframes.
